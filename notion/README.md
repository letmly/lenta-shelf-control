# Notion workspace — структура

> Эти `.md` — заготовки страниц/баз для Notion workspace команды. Когда подключишь Notion MCP, я перенесу их туда как страницы и базы автоматически. Пока можно просто скопировать содержимое в соответствующую страницу Notion.

## Структура workspace

```
🏠 Lenta Hack (home)             ← 01-home.md
├── 🎯 Гипотеза и стратегия       ← 02-hypothesis.md
├── 📋 Задачи (Database, kanban)  ← 03-tasks.md
├── 🗓 Roadmap (Database, timeline)← 04-roadmap.md
├── 🧠 Эксперименты (Database)    ← 05-experiments.md
├── 📚 Ресерч                     ← 06-research.md
├── 👥 Команда и роли             ← 07-team.md
├── 📝 Лог решений                ← 08-decisions.md
└── 🎤 Презентация (draft)        ← 09-pitch.md
```

## Базы данных (Notion databases)

- **Задачи** (03-tasks.md) — карточка задачи: Title, Status (Todo/Doing/Review/Done/Blocked), Day (Д1..Д7), Assignee, Priority, Tags, Estimated hours, Linked PR.
- **Roadmap** (04-roadmap.md) — Date, Milestone, Lead, Artifact.
- **Эксперименты** (05-experiments.md) — Exp ID, Hypothesis, Metric, Baseline, Result, Status, Owner, Notebook link.
- **Лог решений** (08-decisions.md) — Date, Decision, Context, Alternatives considered, Owner.
