# 🎯 Гипотеза и стратегия

## Что мы ставим в центр

**QR-код решает половину задачи.**

В каждом ценнике «Ленты» есть QR, в котором уже структурно зашиты:
- штрихкод
- 4 цены (price1..price4)
- 2 оптовых уровня (кол-во + цена)
- акционные поля

Это 8 полей из 30 — и они декодируются почти со 100% точностью одной библиотекой (pyzbar). Если мы умеем надёжно вырезать ценник из кадра и хотя бы один кадр трека пригоден для декодирования QR → треть CSV закрыта без OCR.

Остальное (название товара, цена «крупным шрифтом», скидка, дата печати, штрихкод цифрами, артикул, код выкладки, тип выкладки, доп. инфо) — печатается **в фиксированных местах** одного из 7 шаблонов. То есть это не свободный OCR, а **заполнение формы** — задача на порядок проще.

## Почему верим

| Сигнал | Аргумент |
|---|---|
| В GT-данных у 100% размеченных ценников QR заполнен | Значит QR физически есть и декодируется |
| Шаблоны жёстко регламентированы по pptx | После классификации ROI известны до пикселя |
| Цветов всего 4 (red/yellow/green/white) | HSV-классификатор без модели |
| ByteTrack даёт точную дедупликацию на коротких траекториях | Robot движется ~равномерно, перекрытия редкие |
| YOLO-nano работает real-time на CPU | Деплой на HF Spaces (CPU free) реалистичен |

## Стратегия по дням

```
Д1 ──> Понять данные, baseline без обучения
Д2 ──> Закрыть QR + детектор (минимум 60% полей доступно)
Д3 ──> Закрыть OCR + парсер (доступно 100% полей, но грязно)
Д4 ──> Первая цифра качества + понять, где провалы
Д5 ──> Целевая оптимизация именно слабых полей
Д6 ──> Деплой + презентация (код заморожен)
Д7 ──> Репетиция + сдача
```

**Принцип:** к концу Д3 у нас должен быть **end-to-end баг-фри пайплайн**, даже если качество ~50 %. Лучше иметь работающее «не очень», чем «почти-готово но не запускается». Полировка качества — на Д4–Д5.

## Чем мы отличаемся от типичной команды

| Типичный подход | Наш подход |
|---|---|
| OCR всего ценника, потом NER | **Шаблонный парсинг** по ROI — точнее и в 5× быстрее |
| Игнорировать QR | **QR — фундамент**: 8 полей бесплатно |
| Каждый кадр → отдельный ценник | **Tracker → дедуп**; один уникальный ценник = одна строка |
| Тяжёлый детектор для recall | **YOLO-nano + fine-tune** на нашей разметке |
| Свой UI на React | **Gradio на HF Spaces** = деплой за 5 минут |
