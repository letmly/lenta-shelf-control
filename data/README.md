## sample.csv — официальный референс формата

3 строки из 26_12-20, демонстрируют:
- **Десятичный разделитель — точка** (`3789.49`, не `3789,49`)
- **bbox координаты с десятичной частью** (`2011.9`, не `2011`)
- **`нет`** — для отсутствующих полей (`price_discount`, `code`)
- **Пусто** (`,,`) — для нераспознанных
- **Строки с запятыми/кавычками — в двойных кавычках**
- `additional_info` может содержать текст вроде `"Сухое"`
- `special_symbols` = `Ш` (штука) / `К` / `Л` / `нет`

Полный формат → 29 колонок (см. `docs/01-task.md`).

## Особенности видео

- **Источник:** робот с фишай-объективом, 4K (3840×2160), ~20 fps, H.264
- **Сценарии:** робот едет вдоль стеллажей, иногда останавливается перед полкой
- **Освещение:** смешанное, блики
- **Дисторсия:** фишай → края сильно искривлены
- **Перекрытия:** часть ценников может быть закрыта товаром
- **Стеклянные витрины:** в некоторых сценах съёмка сквозь стекло
