## Почему видео не в git

- Суммарный размер ~600 МБ.
- Free Git LFS даёт 1 ГБ хранения и 1 ГБ трафика в месяц → лимит закончится после нескольких клонов.
- Решение: видео — в облаке, CSV (метки) — в git.

## Формат CSV (GT)

30 колонок, документировано в `docs/01-task.md`.

Особенности:
- Локаль RU: десятичный разделитель в числах — запятая (`"252,63"`, `"2063,1"`).
- `frame_timestamp` — миллисекунды от начала видео.
- Координаты bbox — в пикселях исходного разрешения (видео ~4K).
- Пропуски: `нет` = поля нет физически; пусто = не распознано.
