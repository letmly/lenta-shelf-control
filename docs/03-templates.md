# 03. Шаблоны ценников

> На основе **`docs/case/Расшифровка ценники.pptx`** (раскладка полей внутри ценника) и **`docs/case/ГМ для ТК.pptx`** (каталог всех вариаций для гипермаркета).

---

## 7 базовых шаблонов («Расшифровка ценники.pptx»)

Каждый шаблон — это фиксированная раскладка полей. После того как ценник вырезан из кадра и классифицирован → ROI каждого поля известно с точностью до пикселя относительно прямоугольника ценника.

| # | Тип | Поля, которые на нём видны |
|---|---|---|
| 1 | Базовый | название, размер скидки, цена без карты, цена по карте, id_sku, дата печати, штрихкод (цифры), QR-код |
| 2 | + код зоны и тип выкладки | то же + `code` + `special_symbols` (Ш/К/Л) |
| 3 | + доп. инфо | то же + `additional_info` |
| 4 | С акцией | название, цена без карты, **цена по акции**, цена по карте, id_sku, дата, QR |
| 5 | Полный с акцией | то же + штрихкод цифрами |
| 6 | С шелфтокером | базовый + блок «дополнительная информация по товару» (номер на весах, «удачная упаковка» и т. д.) |
| 7 | Минимальный | название, цена без карты, цена по карте, дата, id_sku, штрихкод, QR |

## Размеры и форматы («ГМ для ТК.pptx»)

| Формат | Где встречается | Заметки |
|---|---|---|
| **6×6** | компактные ценники для штучных и весовых товаров | базовый размер |
| **6×12** | то же | удлинённые |
| **А5** | средний | вертикальный |
| **А4 вертикаль** | крупные | |
| **А4 горизонт** | крупные | |
| **А3 вертикаль / горизонт** | особо крупные акции | |
| **А2 вертикаль / горизонт** | большие акции | |
| **МНЦ** (мини-ценник) | для свежих продуктов, выпечки, овощей-фруктов | белый / жёлтый / зелёный |

## Механики = цвет ценника

| Механика | Что отображается | Цвет |
|---|---|---|
| **РПЦ** (Регулярная Полочная Цена) | только цена | белый / нейтральный |
| **АПЦ** (Скидка при покупке) | цена без карты + цена по карте + размер скидки | **красный** ← данные у нас |
| **Распродажа** | резкая скидка | красный |
| **Скидка ОТ N шт** (порог-скидка, БУ от X) | оптовые уровни | красный |
| **Скидка ДО N шт** (БУ до X) | ограничение по штукам | красный |
| **BOGOF** | «Buy One Get One Free» | красный |
| **МНЦ-белый** | дата + 100 г / штука | белый |
| **МНЦ-жёлтый** | выпечка, акция | жёлтый |
| **МНЦ-зелёный** | овощи-фрукты | зелёный |
| **ТОП-1000 / СТОЛОТО** | особая полочная цена | красный/жёлтый |

## Единицы измерения

Каждый шаблон бывает в версиях:
- **за 1 шт**
- **за 1 кг**
- **за 100 г**
- **детский** (отдельный шаблон у некоторых форматов)

И с/без «номера кнопки на весах» (актуально для весовых).

## Поле `special_symbols` (тип выкладки)

Печатается мелким значком на самом ценнике, если в системе товар маркирован соответствующим типом:

| Значок | Значение |
|---|---|
| **Ш** | штуки |
| **К** | короб |
| **Л** | лоток |

Видим в наших данных в столбце `special_symbols` (`Ш`, `К`).

## Поле `discount_amount`

> Из ГМ для ТК (примечание к А-форматам): «Если скидка в рублях меньше 100 ₽, отображается в %, если ≥100 ₽ — в рублях».

Значит парсер должен корректно понимать оба формата:
- `-23%`, `-48%`
- `-100 ₽`, `-150 ₽`

В наших размеченных CSV — всё в %.

## Что это даёт для пайплайна

1. **Цвет → механика** определяется напрямую HSV-классификатором (HSV-гистограмма по центральной зоне cropа ценника).
2. **Формат (размер)** — по геометрии bbox + соотношению сторон + размеру относительно соседних ценников на полке.
3. **Шаблон 1–7** — определяет, какие поля искать вообще, и где.
4. После классификации шаблона → таргетные ROI для OCR, а не «свободный» парсинг всей картинки.

Подробнее в `04-architecture.md`.
