# 06. Ресерч моделей и библиотек

> Кратко, по существу. Все варианты — локально-разворачиваемые (требование ТЗ).

## Детекция (ценник как объект)

| Кандидат | Плюсы | Минусы | Берём? |
|---|---|---|---|
| **YOLOv8n / v11n** (Ultralytics) | Простой train, встроенный ByteTrack, ~7 МБ, real-time на CPU | — | ✅ **основной** |
| YOLOv8s | Лучше recall | Тяжелее, на CPU медленнее | резерв если v8n недотянет |
| RT-DETR | SOTA качество | Тяжёлый, нет out-of-box трекинга | нет |
| Detectron2 | Гибкий | Сложно деплоить | нет |

## Трекинг между кадрами

| Кандидат | Плюсы | Минусы | Берём? |
|---|---|---|---|
| **ByteTrack** | Внутри Ultralytics, MotionBased, без ReID-сети | — | ✅ |
| BoT-SORT | Точнее на длинных треках | Тяжелее | резерв |
| DeepSORT | Классика | Нужна ReID-сеть | нет |

## OCR

| Кандидат | Плюсы | Минусы | Берём? |
|---|---|---|---|
| **PaddleOCR (ru)** | RU поддержка, лёгкая mobile-версия, бесплатно | Чуть капризный в установке | ✅ **основной** |
| **RapidOCR** | ONNX-runtime, очень лёгкий | Чуть слабее на RU | резерв |
| TrOCR (microsoft) | Транформер, точно по символам | Тяжелее, не онлайн | резерв при H2 |
| EasyOCR | Простой API, RU | Медленнее на CPU | резерв |
| Tesseract 5 + ru.traineddata | Минимальные зависимости | Слабо на цифрах с фоном | нет |

## QR / штрихкод

| Кандидат | Плюсы | Минусы | Берём? |
|---|---|---|---|
| **pyzbar (ZBar)** | Простой API, надёжно на чётких QR | Зависимость от libzbar | ✅ |
| OpenCV QRCodeDetector | Без доп. зависимостей | Слабее на blur | резерв |
| **ZXing-cpp (Python binding)** | Точнее на blur | Чуть тяжелее ставить | резерв |
| `pylibdmtx` для DataMatrix | — | не наш случай | нет |

## Цвет

- Просто HSV-гистограмма в OpenCV. Без модели.

## UI

| Кандидат | Плюсы | Минусы | Берём? |
|---|---|---|---|
| **Gradio** | Деплой на HF Spaces одной командой, есть video upload + table | Меньше контроля над дизайном | ✅ **основной** |
| Streamlit | Привычнее | Хуже video player | резерв |
| Кастом React + FastAPI | Красиво | Дольше делать | резерв если останется время |

## Хостинг (для деплоя)

| Кандидат | Плюсы | Минусы | Когда выбираем |
|---|---|---|---|
| **HF Spaces (Gradio, CPU free)** | Прямо рекомендован в кейсе, git push deploy | Slow на больших видео | если нет тяжёлых требований к скорости |
| Render | Docker, бесплатные инстансы | Cold start | если нужна REST API |
| Fly.io | Близко к юзеру, гибко | usage-based | если нужно ускорить демо |

## Super-Resolution (на случай H1)

| Кандидат | Плюсы | Минусы |
|---|---|---|
| Real-ESRGAN x2 anime | Лёгкий, ONNX | Не для документов |
| **Real-ESRGAN x2 general** | Универсально | Может перешарпить QR — нужно проверять |
| ESPCN x2 (OpenCV dnn) | Очень быстрый | Слабее качество |

## Полезные открытые датасеты ценников

- **MERIT (Receipt OCR, RU)** — чеки, не ценники, но шрифт похож. https://github.com/...
- **Price Tag detection (Roboflow)** — для предобучения детектора. Множество датасетов под лицензией CC.
- **SROIE 2019** — receipt, есть структурированные поля.

> Предобучение детектора на Roboflow price-tag датасете перед fine-tune на наших 154 ценниках — даст +3..5 pp recall на старте.
