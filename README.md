# Lenta Shelf Control

> Решение для кейса **«Полка под контролем»** — Lenta Tech Life Hack (2026).
>
> Автоматическое распознавание ценников на видеопотоке с робота, движущегося вдоль стеллажей супермаркета. Вход — видео, выход — структурированный CSV со всеми ключевыми полями ценника (название, цены, штрихкод, артикул, скидка, дата печати, цвет, тип выкладки, координаты bbox, поля QR-кода).

---

## TL;DR

- **Задача:** видео → CSV из 30 полей на каждый уникальный ценник.
- **Метрика успеха:** доля ценников из контрольного видео, у которых ≥80 % полей распознаны верно. Цель — ≥70 % таких ценников.
- **Срок:** 7 дней.
- **Команда:** 4 человека (см. [§ Команда](#команда)).
- **Гипотеза:** QR + template-aware OCR + трекинг → бьём порог. Подробнее → [`docs/05-hypothesis.md`](docs/05-hypothesis.md).

## Архитектура (кратко)

```
Видео (1080p–4K, ~25 fps)
   │
   ▼
[Sampling]  ── 1–3 fps + отбор по резкости
   │
   ▼
[Детектор YOLO]  ── bbox ценников (fine-tune на CSV-разметке)
   │
   ▼
[ByteTrack]  ── один ценник = один track_id (дедуп между кадрами)
   │
   ▼
   ├─[QR-декодер pyzbar]  → barcode, price1..4_qr, опт, action
   ├─[Цвет-классификатор HSV] → color (red / yellow / green / white)
   ├─[Template-классификатор] → формат ценника (6×6 / А5 / А4 / А3 / А2 / МНЦ)
   └─[OCR PaddleOCR RU]      → text-поля по template-map
   │
   ▼
[Парсер шаблонов]  ── маппинг ROI → CSV-поля
   │
   ▼
[Aggregator]  ── голосование по полям между кадрами одного track_id
   │
   ▼
output.csv  ── 30 колонок согласно ТЗ
```

Подробности — [`docs/04-architecture.md`](docs/04-architecture.md).

## Ограничения (из ТЗ)

- ❌ Никаких облачных API (OpenAI, Yandex Vision, Google Cloud) — только локально-разворачиваемое.
- ❌ Ручная разметка участниками запрещена. Автоматическая (включая использование уже размеченных CSV как ground truth) — разрешена.
- ✅ Модель должна быть лёгкой, желательно — оптимизируема под RKNN/int8.
- ✅ Поощряется работа на ограниченных вычислительных ресурсах.

## Как запустить

> ⚠️ На текущем коммите код — заготовка. Реальный пайплайн появляется с Д2.

```bash
# 1. Установка
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Скачать данные
python scripts/fetch_data.py

# 3. Прогнать пайплайн на видео
python scripts/run_pipeline.py \
    --video data/labeled/43_15/43_15.mp4 \
    --output outputs/43_15.csv

# 4. Сверить с GT
python scripts/evaluate.py \
    --pred outputs/43_15.csv \
    --gt   data/labeled/43_15/43_15.csv

# 5. Поднять UI локально
python ui/app.py
```
